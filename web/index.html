03 / HOW IT WORKS

Designed for an analyst,
built to be checked.

01

Acquire & validate

Download a complete date-and-product slice from the CFPB API. Check duplicates, dates, row counts, and source provenance.

02

Measure & screen

Aggregate weekly issues with Python. Compare with a four-week baseline and surface only material jumps that pass documented thresholds.

03

Ask with evidence

A local retrieval layer answers questions from generated metric cards and cites the project files. MCP tools expose the same evidence to AI clients.
